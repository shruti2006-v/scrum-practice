
# Agile Project Lifecycle Using Jira with DevOps Integration

## Aim
To implement the Agile project lifecycle using Jira and integrate it with GitHub.

## Tools Used
- Jira
- Git
- GitHub
- GitHub Actions

## Project Tasks
1. Create and manage an Agile project in Jira.
2. Organize tasks into a sprint.
3. Track tasks using the Jira workflow.
4. Store project files in GitHub.
5. Demonstrate continuous integration using GitHub Actions.

## Result
The Agile project lifecycle was demonstrated using Jira and GitHub.
